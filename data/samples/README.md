# Sample media

TapeGrade generates an original 8-second basketball court schematic with fictional
players on the first mock scan. The scene generator and deterministic observations
share geometry. This is explicitly simulated footage, not a real NBA highlight or
an inference benchmark. No network downloads are needed. Generated MP4s are ignored.

Upload an MP4/MOV you have rights to process in the Film Library. It is normalized
to 960×540, 12 fps, no audio, and the first 30 seconds (or configured shorter limit).
In live mode only user uploads are selected. Mock models reject identity verification
of user footage rather than invent an answer. Fictional players need footage clearly
associated with the fictional identity, or update the demo provider with your own
permitted player metadata before using real sports footage.
